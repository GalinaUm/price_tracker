# Price Tracker

Отслеживает цены на криптовалюты и присылает уведомление, когда цена достигает желаемого уровня (например, когда биткоин падает до вашей целевой цены).

## Стек
- **FastAPI** — REST API
- **Celery** — фоновые задачи (проверка цен)
- **Redis** — брокер очередей
- **SQLite + SQLAlchemy** — хранение данных
- **Vanilla JavaScript** — фронтенд

## Что умеет
- Добавлять товары (монеты) с символом из CoinGecko
- Создавать подписки: товар + email + целевая цена
- Каждую минуту (Celery Beat) проверять актуальные цены через API CoinGecko
- Сохранять историю цен в базу
- Уведомлять (в лог воркера), когда цена достигла целевой
- Показывать историю цен на простом графике `<canvas>`

## Как запустить локально

### 1. Redis
Запусти Redis-сервер (в отдельном окне):
```
redis-server
```

### 2. Celery worker
```
celery -A worker worker --loglevel=info --pool=solo
```
> `--pool=solo` обязателен на Windows (prefork не работает).

### 3. Celery Beat (расписание)
```
celery -A worker beat --loglevel=info
```

### 4. FastAPI
```
uvicorn main:app --reload
```

### 5. Открыть фронтенд
```
http://127.0.0.1:8000/static/index.html
```

Документация API доступна на `http://127.0.0.1:8000/docs`.

## Как пользоваться
1. В форме «Добавить товар» укажите название и символ монеты (например `bitcoin`, `ethereum`).
2. В форме «Создать подписку» выберите товар, укажите email и целевую цену.
3. Каждую минуту цена проверяется автоматически. Когда текущая цена становится **≤** целевой, в лог воркера выводится уведомление.
4. В секции «История цен» выберите товар, чтобы увидеть график изменения цены.

